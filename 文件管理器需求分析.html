文件批量整理器 · 需求分析

用户拖入 → 批量整理 → 输出分类文件夹

视角：用户 + 开发者 面向数据：DFD 面向对象：OOA 可视化建模：Mermaid

一、需求总览

产品目标：接收用户拖入的文件/文件夹，按规则自动分类，生成对应分类目录并归类文件。全程遵循需求工程方法，从开发者与用户双视角分析。

用户视角 体验 / 行为

  • 拖拽导入文件，无需手敲路径
  • 可视化配置分类规则，先预览后执行
  • 不误删原文件，可回退
  • 结果与异常清晰可见

开发者视角 架构 / 实现

  • 模块解耦：采集 / 规则 / 目录 / 文件操作独立
  • 元数据驱动分类，不解析文件内容
  • 权限与 IO 异常分级处理
  • 预览与执行分离，磁盘操作可控

二、详细需求

功能性需求（F）与非功能性需求（N）双表呈现。

2.1 功能性需求（用户视角可感知的能力）

编号需求描述验收要点
F1支持拖拽批量导入本地文件或文件夹一次可拖入 ≥100 个文件，提示不可拖入的类型
F2支持按后缀 / 创建时间 / 文件大小等维度配置分类规则规则可视化勾选，可多维度组合
F3一键批量整理，自动创建分类文件夹目录不存在时自动递归创建
F4执行前可视化预览分类结构，不落盘预览为内存模拟，不写磁盘
F5支持复制 / 移动两种操作模式（默认复制）移动模式二次确认
F6输出操作日志与异常文件清单记录成功数量、失败原因、文件路径
F7可自定义输出根目录并保存/加载规则配置配置持久化，下次可复用

2.2 非功能性需求（开发者视角的质量约束）

编号需求描述验收要点
N1安全：默认不删除原文件，操作前校验权限复制失败不残留半成品，提供回退路径
N2性能：大文件不阻塞 UI异步处理 + 进度反馈，千级文件可用
N3易用：拖拽即用，可视化分类树预览无命令行依赖，首屏 3 步可达
N4容错：跳过占用/损坏/无权限文件，不崩溃异常记录入日志，单文件失败不影响整体

采用 Yourdon 符号：矩形=外部实体，圆角矩形=处理，平行线=数据存储，箭头=数据流。

整体系统与唯一外部实体「用户」之间的数据交互。

3.2 DFD 1 层（功能分解）

将系统拆分为 4 个子处理过程，数据在过程与存储间流动。

flowchart LR U(["用户"]) P1(["P1 采集文件与\n提取元数据"]) P2(["P2 分类计算\n(预览)"]) P3(["P3 创建分类目录"]) P4(["P4 执行复制/移动\n+日志"]) D1[("D1 规则配置")] D2[("D2 操作日志")] U -- 拖拽文件 --> P1 P1 -- 文件元数据列表 --> P2 U -- 分类规则 --> P2 P2 <--> D1 P2 -- 文件-目录映射表 --> P3 P3 -- 目录创建结果 --> P4 P4 -- 操作结果/异常清单 --> U P4 --> D2
数据流说明： P1 输出文件元数据（名/后缀/大小/时间/原路径）→ P2 按规则产出「文件-目标目录」映射 → P3 校验并批量建目录 → P4 执行文件操作并落日志。

五、业务活动流程图

端到端的主流程，含预览回退与异常处理分支。

5.1 批量整理主流程

flowchart TD A([开始]) --> B[用户拖拽文件到窗口] B --> C[系统读取全部文件元信息] C --> D[用户配置分类规则·输出目录·复制/移动] D --> E[系统计算分类结构,生成预览树] E --> F{用户确认执行?} F -- 否 --> Z([结束:仅预览,不改磁盘]) F -- 是 --> G[校验权限] G --> H[批量创建所有目标分类文件夹] H --> I[循环处理每个文件] I --> J{复制/移动成功?} J -- 是 --> K[标记成功] J -- 否 --> L[捕获异常,加入失败清单] K --> M[下一个文件] L --> M M --> I I --> N[生成操作日志] N --> O[返回整理报告:成功数+失败清单] O --> Z

六、需求边界与假设

  • 本系统不做文件内容识别，仅基于文件元信息分类；按内容分类属扩展需求。
  • 预览阶段全部在内存运算，不修改本地磁盘；执行前可回退。
  • 移动操作存在文件丢失风险，默认推荐复制模式，移动需二次确认。
